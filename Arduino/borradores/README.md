# Borradores archivados

Esta carpeta guarda notas y pruebas previas que estaban mezcladas con los ejemplos funcionales. Se conservan como referencia; los fragmentos de esta carpeta no se ejecutan ni forman parte de los pasos de instalación.

- `notas/`: apuntes y fragmentos HTML/JavaScript incompletos.
- `socket-incompleto/`: paquete de Socket.IO que no tenía un servidor ni un punto de entrada.
